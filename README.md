# CallRecorder (مشروع Android Studio - نسخة أولية)
1. افتح المجلد في Android Studio ثم Sync وRun على هاتفك.
2. اضغط "السماح بالصلاحيات" ثم فعّل خدمة إمكانية الوصول "تسجيل مكالمات واتساب".
3. المكالمات العادية: تسجيل تلقائي عند الرد. واتساب: تلقائي عبر خدمة إمكانية الوصول.
4. اضغط على أي تسجيل ثم اختر Drive لحفظه.
ملاحظة: التسجيل من الميكروفون؛ للحصول على صوت الطرف الآخر شغّل مكبر الصوت.
